# 🎵 2D Rhythm Action                                                                                                            
                                                                                                                                 
  > BPM에 맞춰 화살표를 베는 2D 리듬 액션 게임                                                                                         
   
  ## 📋 프로젝트 개요                                                                                                              
                                                                                                                                 
  | 항목 | 내용 |                                                                                                                  
  |:---:|:---|
  | **개발 기간** | 2025.11.17 ~ 2025.11.19 (36시간 게임잼) |                                                                      
  | **팀 구성** | 1인 개발 |                                                                                                       
  | **플랫폼** | Windows PC |                                                                                                      
  | **장르** | 2D 리듬 액션 |                                                                                                      
  | **담당 역할** | 전체 설계 및 구현 (코어 아키텍처, DSP 음악 동기화, 판정 시스템, 노트 시스템, UI/UX, 배경 연출) |               
                                                                                                                                   
  ## 🎮 게임 소개                                                                                                                  
                                                                                                                                   
  BPM에 동기화된 노트가 화면을 가로지르면, 정확한 타이밍에 키를 입력해 베어 넘기는 2D 리듬 액션 게임입니다.                   
   
  4방향(W/A/S/D) 노트가 음악의 비트에 맞춰 등장하며, Perfect(±0.1초) / Good(±0.5초) / Miss 3단계 판정으로 점수와 콤보를 쌓아 곡을  
  완주하세요.     
                                                                                                                                   
  ## ⭐ 주요 기능 및 콘텐츠                                                                                                
   
  ### 🎶 DSP 기반 음악 동기화                                                                                                      
  - `AudioSettings.dspTime` 기반 프레임 독립적 타이밍
  - BPM 역산으로 노트 TargetTime 산출, 이동 시간을 역산하여 SpawnTime 결정                                                         
  - `PlayScheduled`로 지연 재생하여 초기화 타이밍과 음악 시작 분리                                                                 
                                                                                                                                   
  ### 🎯 판정 & 스코어링 시스템                                                                                                    
  - Perfect(±0.1s) / Good(±0.5s) / Miss 시간 차이 기반 3단계 판정
  - 콤보 보너스 = CurrentCombo × 0.2, PlayerPrefs 최고점수 영속 저장                                                               
  - 동일 타입 노트 중 시간 차이가 가장 작은 노트를 탐색하여 입력 매칭                                                              
   
  ### 🎼 채보 시스템                                                                                                               
  - 랜덤 생성 / 섹션 기반 생성 두 가지 채보 모드
  - BeatSection 구조로 구간별 비트 간격을 설정하여 난이도 곡선 설계                                                                
                                                                                                                                   
  ### ✨ Game Feel 피드백 체인
  - 판정별 차등 UI 애니메이션 (DOTween PunchScale, Color Flash, Shake)                                                             
  - 판정 등급에 따른 카메라 셰이크 강도·길이 차등 적용
  - 방향별 ±0.075~0.15 히트 사운드 Pitch 변조                                                                                      
  - Miss 시 하트 컨테이너 흔들림 + 빨간 플래시 복합 피드백
                                                                                                                                   
  ### 🎨 배경 연출
  - AnimationCurve 보간으로 BPM 비트 진행도에 따른 배경 스케일 맥동                                                                
  - 무한 스크롤 패럴랙스 + 카메라 Orthographic Size 자동 피팅                                                                      
   
  ## 🕹 조작법                                                                                                                     
                  
  | 키 | 동작 |                                                                                                                    
  |:---:|:---|
  | `W / ↑` | 위쪽 노트 타격 |                                                                                                     
  | `A / ←` | 왼쪽 노트 타격 |
  | `S / ↓` | 아래쪽 노트 타격 |
  | `D / →` | 오른쪽 노트 타격 |                                                                                                   
  | `ESC` | 일시정지 / 재개 |
